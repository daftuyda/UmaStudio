# UmaStudio 0.1.2

This release adds Japanese asset support to the Windows app, continuous animation
playback, and fixes for posing and hair/clothing collisions.

## Game folders and names

- Switch between Global and Japan in the desktop app's Settings button.
- Detect Steam installations or select install and downloaded-data folders separately.
- Remember folders and keep converted assets and file-list caches separate for each source.
- Show English character and outfit labels while continuing to use JP assets.
  Labels without an available translation use an English category and ID.
- Support protected JP data through a compatible installed Global reader and physics
  library, using the JP character's own model, skeleton and physics settings.
- Prevent a new build from opening an incompatible older app's interface.

## Animations, faces and cameras

- Play complete cut-ins and ordered start/loop/end sequences continuously, with
  individual shots still available. Scrubbing and exports follow the full sequence.
- Follow downloaded facial animation, including expressions and gaze, with manual
  expression controls available.
- Follow the animation's intended camera and character placement. Restore the manual
  camera when disabled and fall back to it for shots without a camera track.
- Automatically load supported attached props, their animations and shot visibility.
  Remember a manual prop setup for animations without a detected association.

## Posing and physics

- Fix joint dragging that stayed active after releasing the mouse.
- Add steadier joint-axis movement and Shift for fine adjustments.
- Recover from rapid drags, pointer cancellation and focus loss.
- Pause playback during joint dragging and fix reset, undo and accumulating joint offsets.
- Preserve shared physics colliders, scale capsule endpoints consistently and cap native
  collider indices to their available slots.
- Add body/clothing surface collisions and an adjustable clearance in Look.
- Smooth collision corrections separately from the native spring simulation to reduce
  twitching, including Manhattan Cafe's tie and Oguri Cap's side hair.
- Support meshes with fewer than four skin influences when converting outfits.

## Loading and distribution

- Load textures and animation companions concurrently, reuse repeated requests, and
  cache facial/camera companions on disk.
- Prepare prop/background previews when needed and discard superseded loading requests.
- Build and test Windows downloads through GitHub Actions on pull requests and pushes
  to main; publish releases when a matching version tag is pushed.
- Include a ZIP integrity check, SHA-256 checksum, license and release notes.

## Requirements and limits

Extract the ZIP and run `UmaStudio/UmaStudio.exe`. Windows 10 or 11 and locally
downloaded game assets are required. Protected JP builds may also need a compatible
Global installation. Video export requires ffmpeg.

Face/camera/prop support depends on the downloaded animation data. Detached or ambiguous
prop arrangements may need a manual setup. Loose garments do not collide with one another,
and extreme poses can still clip. No game assets are included.
