# UmaStudio 0.1.3

Create and edit animations in the Windows app, import Unity Humanoid clips, and
export videos faster with reliable progress and cancellation.

## Custom animation editor and imports

- Add an Animate tab in the native Windows app, with a keyframe timeline and frame stepping.
- Create full-pose body/finger keys, facial expressions, and character movement from a neutral pose.
- Copy, paste, move, delete, and undo keyframes with smooth, linear, or held transitions.
- Choose 30/60 fps, a duration up to 120 seconds, and looping or play-once playback.
- Save/open editable `.umaanim` projects and resume a locally stored draft.
- Play and export authored motion through the existing video and animated GLB tools,
  including the final GLB keyframe, with hair/clothing physics applied separately.
- Keep full-size/chibi projects separate. Chibi facial tiles use held changes and are
  supported in video; animated texture tiles are not exported in GLB.
- Import Unity Humanoid `.anim` files, including the supplied DanceMoves and Orange Justice
  examples, onto full-size Uma skeletons with body and finger retargeting.
- Use an installed Unity Editor in a private background conversion project. Cache results
  per animation and skeleton; store the converted motion in version 2 `.umaanim` files.
- Keep imported motion separate from editable pose/expression correction keys. Reopening,
  playback, editing and export of saved projects do not require Unity.
- Generic/legacy bone clips, FBX/BVH, imported facial/prop tracks, camera/prop keyframes,
  and foot locking remain future work.

## Faster, more reliable video exports

- Fix intermittent video export connection failures by reusing local HTTP connections
  and safely retrying frame and physics requests without duplicating frames or simulation ticks.
- Compress frame transfers without image loss, reuse GPU targets and pixel buffers, and
  overlap uploads with rendering. Encode frame images on a worker so background windows
  do not delay every captured frame.
- Stream GIF palettes per frame to bound memory use. Use faster MP4/WebM encoder settings;
  the MP4 quality target remains CRF 16, with potentially larger files.
- Keep encoding off request threads, show export speed/elapsed time/remaining estimates
  and encoding progress, and allow cancellation during both rendering and encoding.
- Stop stalled encoders, report per-export diagnostics, remove failed/partial outputs,
  and restore the previous playhead and camera after exporting.

## Requirements

Extract the ZIP and run `UmaStudio/UmaStudio.exe`. Windows 10 or 11 and locally
downloaded game assets are required. Video export requires ffmpeg. Importing Unity
Humanoid `.anim` files requires an installed Unity Editor; saved `.umaanim` projects
can be played, edited and exported without Unity.
